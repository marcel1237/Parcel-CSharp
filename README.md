# Parcel C#

**Parcel C#** is a sophisticated, AI-driven Industrial Development Toolkit built on **.NET 8** and **Avalonia UI 11**. It integrates multi-agent intelligence, SQLite session persistence, incremental backup snapshots, and a comprehensive cross-platform desktop UI to streamline complex C#, .NET, and Shell Scripting workflows.

---

## 🚀 Key Features

### 🧠 SS AI Agent & QLM Engine (Extraordinary Shell Intelligence)
- **Multi-Agent Orchestration:** Seamlessly triages requests between local semantic analysis, QLM rule enforcement, and deep reasoning via LLMs (Gemini & OpenAI).
- **SSQLM Standards:** Enforces high-fidelity Shell Script Quality Language Model (SSQLM) standards for safety, atomicity, and industrial resilience.
- **Deep Technical Research:** Synthesizes implementation patterns from multiple technical sources automatically.

### 🎨 Cross-Platform UI & Designer Engine
- **Modern Avalonia UI Bridge:** Advanced XAML-based desktop interface with full 1:1 parity with the original Qt 6 panes (Dashboard, Package Explorer, Code Editor, AI Console, DBMS Explorer, Git & Versions, Saves & Backups, Terminals, Browser, and Frameworks).
- **Cyber-Dark Theme:** Professional, high-contrast dark aesthetic optimized for long-duration industrial development.

### 🛡️ Core Services & Safety
- **Backup Service:** Incremental, SQLite-based project versioning and safe restoration points (`.parcel_backups.db`).
- **Persistence Layer:** Secure storage for project session management and settings via `Microsoft.Data.Sqlite`.
- **Git & Tooling Integration:** Native Git repository status and version logging.

## 🛠️ Build & Installation

### Prerequisites
- **.NET 8 SDK** (or later)

### Build Instructions
```bash
# Clone the repository
git clone https://github.com/your-repo/parcel-csharp.git
cd parcel-csharp

# Build the solution
dotnet build ParcelCSharp.sln
```

### Running the Application
```bash
dotnet run --project ParcelDesktop/ParcelDesktop.csproj
```
